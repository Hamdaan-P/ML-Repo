## Project Overview

This project builds a complete data science pipeline on the Heart Disease UCI dataset (Cleveland Clinic). It covers data cleaning, SQL storage, exploratory data analysis, and machine learning — from raw CSV to a trained classification model with full evaluation.

---

## Dataset

**Name:** Heart Disease UCI (Cleveland Clinic Foundation)
**Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/heart+disease)
**Rows:** 208 (after cleaning) | **Columns:** 14
**Target:** Binary — 0 = No Heart Disease, 1 = Has Heart Disease

## How to Run on a Fresh Machine

### 1. Clone the repository
```bash
git clone https://github.com/your-username/zaryahplus-internship.git
cd zaryahplus-internship
```

### 2. Install required libraries
```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

### 3. Run each part in order

> **Important:** Run Part A first — it creates `heart_data.db` which Parts B and C depend on.

```bash
# Part A — Data Cleaning & SQL Storage
python part_a_cleaning.py

# Part B — Exploratory Data Analysis
python part_b_eda.py

# Part C — Machine Learning
python part_c_ml.py
```

All charts will be saved automatically inside the `charts/` folder.

## Part A — Data Cleaning & SQL Storage

**What it does:**
- Loads raw CSV using pandas
- Handles missing values — drops rows with NaN (< 2% of data)
- Removes 14 duplicate rows
- Renames all columns from abbreviations to readable names
- Saves cleaned data into SQLite database (`heart_data.db`, table: `patients`)
- Runs 4 SQL queries and prints results

**Key finding:** 14 duplicate rows removed. No missing values in this sample. Target column converted from 5 severity levels (0–4) to binary (0/1).

## Part C — Machine Learning

**Models trained:** Logistic Regression and Random Forest

**Class imbalance handling:** `class_weight='balanced'` applied to both models

**Results:**

| Metric | Logistic Regression | Random Forest |
|---|---|---|
| Accuracy | 83.3% | **92.9%** |
| Precision | 0.70 | **0.93** |
| Recall | 1.00 | 0.88 |
| F1 Score | 0.82 | **0.90** |

**Winner:** Random Forest — best overall balance across all metrics.
